🧪 נתוני דמו

יוצר 10 קבוצות ("קבוצה 1".."קבוצה 10"), 30 שחקנים לדוגמה (3 לכל קבוצה, עם הנדיקפ ידני אקראי בין 10-65), ותוכנית משחקים מלאה (סבב יחיד, החל מהיום, מחזור שבועי). זמין רק בסביבת ה-DEMO הזו.

שם הליגה והלוגו מוצגים בכותרת האתר הציבורי (עמוד הדירוג) וכאן בממשק הניהול.

🎯 כללי ניקוד

🎳 הנדיקפ

הנדיקפ מחושב אוטומטית לפי הממוצע האישי של כל שחקן, ומשפיע רק על תוצאות וניקוד ברמת המשחק הקבוצתי — טבלת הדירוג האישי תמיד מציגה ממוצע וציונים טהורים (Scratch).

נוסחה: הנדיקפ = (ציון בסיס − ממוצע שחקן) × אחוז. שחקן חדש ללא היסטוריה מקבל הנדיקפ 0.

🎳 מסלולים

קובע את טווח מספרי המסלולים של האולם (למשל 1-10, או 11-18). המסלולים יופיעו כזוגות לבחירה בלוח המשחקים, במקום טקסט חופשי.

👥 קבוצה חדשה

🎳 הקמת קבוצות

כל קבוצה תיווצר עם שם ברירת מחדל ("קבוצה 1", "קבוצה 2"...) וצבע ייחודי משלה. אפשר לשנות שם/צבע בהמשך דרך "ערוך".

🏋️ שחקן חדש

בשימוש רק כל עוד לשחקן אין היסטוריית משחקים במערכת — לאחר המשחק הראשון שלו ההנדיקפ עובר לחישוב אוטומטי לפי הממוצע.

📅 משחק חדש

🎲 יצירת תוכנית משחקים אוטומטית

כל קבוצה תשחק נגד כל קבוצה אחרת, על פי מספר הקבוצות הרשומות במערכת. אם מספר הקבוצות אי-זוגי, קבוצה אחת תנוח בכל מחזור.

❓ איך מקבלים Firebase Config?
  1. כנס ל-firebase.google.com והתחבר עם חשבון Google
  2. לחץ Add project ← תן שם ← המשך
  3. בתפריט השמאלי ← ⚙️ Project settings
  4. תחת Your apps ← לחץ </> (Web) ← Register app
  5. העתק את אובייקט ה-firebaseConfig והדבק למעלה
  6. חזור לפאנל ← Build → Firestore Database ← Create database ← בחר Start in test mode
  7. לאחר החיבור, השתמש באותו Config גם בעמוד הציבורי (index.html) — הוראות בהגדרות
